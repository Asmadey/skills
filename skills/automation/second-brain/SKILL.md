# Second Brain (LLM Wiki Engine)

## 1. When to use
- Добавление новой статьи, видео или документа в базу знаний.
- Поиск ответов на сложные вопросы, требующие синтеза нескольких заметок.
- Регулярная проверка здоровья базы (чистка дублей, обновление старых данных).

## 2. Validation & Prerequisites
- [ ] Пути в Obsidian доступны (sources/, wiki/, assets/).
- [ ] Файлы `wiki/index.md` и `wiki/log.md` инициализированы.

## 3. Workflow (Checklist)

### Ingest (New Source)
- [ ] Прочитать исходный файл из `sources/`.
- [ ] Обсудить ключевые инсайты с пользователем (опционально для Batch).
- [ ] Создать/обновить страницу в `wiki/` (используя kebab-case).
- [ ] Обновить `wiki/index.md` (добавить ссылку и саммари).
- [ ] Добавить запись в `wiki/log.md`.
- [ ] Найти связанные страницы и добавить `[[wikilinks]]`.

### Query
- [ ] Найти релевантные страницы через `wiki/index.md` или `grep`.
- [ ] Синтезировать ответ с цитированием страниц wiki.
- [ ] **Crucial**: Если ответ нетривиален, предложить сохранить его как новую страницу в `wiki/`.

### Lint (Health Check)
- [ ] Поиск противоречий между новыми и старым данными.
- [ ] Поиск "сиротских" страниц (без входящих ссылок).
- [ ] Поиск упоминаний концепций, не имеющих своих страниц.

## 4. Instructions
- **Naming**: Файлы всегда в `kebab-case`. Заголовки человекочитаемые.
- **Atomic Notes**: Стремиться к атомарности заметок. Одна основная мысль на страницу.
- **Log Format**: `## [YYYY-MM-DD] [action] | [Title]`
