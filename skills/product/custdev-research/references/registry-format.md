# Формат реестра исследований

Реестр — плоский Markdown-файл, по строке на прогон. Путь по умолчанию:
`<BASE_DIR>/Meets/реестр_кастдевов.md`, переопределяется через env `CUSTDEV_REGISTRY`.

## Колонки

| # | Колонка | Содержимое |
| :--- | :--- | :--- |
| 1 | Дата и время | `2026-11-12 17:34:11` — момент прогона (`datetime.now()`), локальное время |
| 2 | Записи | ссылки на исходники через запятую; если файл перемещён — `имя.webm (источник перемещён/удалён)` |
| 3 | Ведущий | имя интервьюера/фасилитатора |
| 4 | Респонденты | через запятую, в порядке из `--respondents` |
| 5 | Профиль кратко | первые 60 символов профиля основного респондента + `...` |
| 6 | Стенограммы | ссылки на JSON в `Meets/transcripts/` |
| 7 | DOCX | ссылка на документ |
| 8 | Фоллоуап | ссылка на `.txt` |
| 9 | Статус | `Успешно ✅` / причина сбоя |

## Пример строки

```markdown
| 2026-11-12 17:34:11 | [Запись встречи 12.11.webm](...) | Интервьюер (JGGL) | Глеб, Камиль, Стас | Глеб — Глеб, 27 лет, нейродизайнер (направление архитект... | [группа_12.11_ч1.json](...), [группа_12.11_ч2.json](...) | [Стенограмма_и_Фоллоуап_Группа_12.11.docx](...) | [группа_12.11.txt](...) | Успешно ✅ |
```

Ссылки пишутся относительными путями от `BASE_DIR` и URL-кодируются (`urllib.parse.quote`),
чтобы кириллица и пробелы не ломали рендер в Obsidian/GitHub.

## Заголовок файла (создать один раз)

```markdown
# Реестр кастдев-исследований JGGL

| Дата | Записи | Ведущий | Респонденты | Профиль кратко | Стенограммы | DOCX | Фоллоуап | Статус |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
```

Скрипты дописывают строку в конец файла, заголовок не создают — его добавляют один раз вручную,
чтобы не затирать существующий реестр.

## Зачем это нужно

Реестр — единственное место, где видно **кого** уже исследовали и **когда**: по нему видно, что
покрыто, кого нужно добрать, и какие записи уже обработаны (что экономит токены — повторный
прогон всё равно берётся из кэша, но лучше не запускать его вовсе).
