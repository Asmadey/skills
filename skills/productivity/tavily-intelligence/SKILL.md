# Tavily Intelligence Suite

## 1. Когда использовать
- **Глубокий поиск (Search):** Когда нужен поиск с ИИ-контекстом, превышающий возможности обычных поисковиков.
- **Извлечение (Extract):** Когда нужно получить чистый структурированный текст из конкретных URL без лишнего HTML-мусора.
- **Сканирование (Crawl):** Когда требуется глубокий анализ всего сайта или его подразделов.

## 2. Проверка и предусловия
- [ ] Установлен Python 3.x
- [ ] Установлена библиотека: `pip install tavily-python`
- [ ] API-ключ настроен в скриптах (или передан в переменные окружения)

## 3. Рабочий процесс (Checklist)
- [ ] Шаг 1: Выбрать режим работы (Search, Extract, Crawl).
- [ ] Шаг 2: Подготовить входные данные (Query или URL).
- [ ] Шаг 3: Запустить соответствующий скрипт из директории `scripts/`.
- [ ] Шаг 4: Анализировать JSON-ответ.

## 4. Инструкции
### Использование вспомогательных скриптов

#### Глубокий поиск
```bash
python scripts/search.py "Ваш запрос для глубокого поиска"
```

#### Извлечение контента
```bash
python scripts/extract.py https://example.com/page1 https://example.com/page2
```

#### Краулинг сайта
```bash
python scripts/crawl.py https://example.com
```

### Принципы работы (Heuristics)
- Используйте `Crawl` экономно, так как это потребляет больше токенов/кредитов API.
- Для `Search` используйте `search_depth="advanced"` для получения максимально релевантных ответов.
- При получении данных через `Extract`, Tavily возвращает чистый контент, готовый для подачи в LLM.

## 5. Ресурсы
- `scripts/search.py`: Скрипт продвинутого поиска.
- `scripts/extract.py`: Скрипт извлечения текста из URL.
- `scripts/crawl.py`: Скрипт глубокого сканирования сайта.
