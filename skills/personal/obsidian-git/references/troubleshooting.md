# Устранение неполадок (Troubleshooting) Obsidian Git

Руководство по решению распространенных проблем синхронизации и сбоев плагина.

---

## 1. Зависание на Pull/Push без ошибок (Infinite Pull/Push)
* **Причина:** Git ожидает ввода логина/пароля в фоновом терминале, который не отображается в UI Obsidian.
* **Решение:**
  1. Откройте терминал в папке хранилища (vault).
  2. Выполните `git pull` и `git push`.
  3. Введите учетные данные.
  4. Настройте credential helper (см. `references/authentication.md`), чтобы учетные данные сохранялись навсегда.

---

## 2. Ошибка "xcrun: error: invalid active developer path" (macOS)
* **Причина:** Обновление macOS сбросило привязку инструментов командной строки Xcode.
* **Решение:**
  Выполните в терминале:
  ```bash
  xcode-select --install
  ```

---

## 3. Блокировка индекса Git: "index.lock File exists"
* **Причина:** Предыдущая операция git была принудительно завершена или упала, оставив блокировочный файл.
* **Решение:**
  ```bash
  # Убедитесь, что никакой процесс git не выполняется
  rm -f .git/index.lock
  ```

---

## 4. Конфликты слияния (Merge Conflicts)
* **Симптом:** В заметках появляются маркеры вида `<<<<<<< HEAD`, `=======`, `>>>>>>> origin/main`.
* **Решение:**
  1. Запустите скрипт проверки конфликтов:
     ```bash
     python3 scripts/scan_conflicts.py /path/to/vault
     ```
  2. Разрешите конфликт вручную в Obsidian или через VS Code/терминал:
     - Оставьте нужный вариант текста.
     - Удалите служебные маркеры `<<<<<<<`, `=======`, `>>>>>>>`.
  3. Зафиксируйте слияние:
     ```bash
     git add .
     git commit -m "resolve: merge conflict in notes"
     git push
     ```

---

## 5. Файлы из `.gitignore` продолжают коммититься
* **Причина:** Файлы уже были добавлены в индекс Git до того, как их добавили в `.gitignore`.
* **Решение:**
  Удалите файлы из индекса Git без удаления их с диска:
  ```bash
  git rm -r --cached .obsidian/workspace.json
  git commit -m "chore: stop tracking workspace.json"
  ```

---

## 6. Конфликт с облачными сервисами (iCloud, Dropbox, OneDrive)
* **Симптом:** Резкое замедление запуска Obsidian, повреждение `.git/` папки.
* **Рекомендация:** **Никогда не совмещайте одновременную синхронизацию папки `.git` через iCloud/Dropbox и Obsidian Git.**
  Если требуется доступ с мобильных устройств через iCloud:
  - Вынесите репозиторий `.git` за пределы синхронизируемой iCloud папки, создав в хранилище файл `.git` со строкой:
    ```text
    gitdir: /absolute/path/to/real/git-directory
    ```
