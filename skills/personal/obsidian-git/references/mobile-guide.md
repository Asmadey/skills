# Особенности и ограничения синхронизации на Mobile (iOS / Android)

На мобильных платформах (iOS и Android) операционные системы не предоставляют нативный бинарный файл `git`. Плагин obsidian-git использует библиотеку **isomorphic-git** на JavaScript.

---

## 1. Фундаментальные ограничения isomorphic-git

1. **Нет поддержки SSH:**
   Авторизация возможна **только по HTTPS** с использованием Personal Access Token (PAT).
2. **Лимит оперативной памяти:**
   Большие хранилища (> 300–500 МБ или тысячи бинарных вложений/изображений) могут вызывать сбои мобильного приложения из-за исчерпания памяти (Out-Of-Memory / Buffer Overflow).
3. **Нет поддержки Submodules и Rebase:**
   Стратегия слияния поддерживается только стандартным `merge`.

---

## 2. Альтернативные и более надежные способы синхронизации на Mobile

### Вариант А: Working Copy (только iOS)
1. Установите приложение **Working Copy** из App Store.
2. Клонируйте ваш репозиторий заметок внутри Working Copy.
3. В Obsidian для iOS выберите *"Open folder as vault"* и укажите папку репозитория из Working Copy (через системный провайдер файлов Files).
4. Преимущество: полноценный нативный Git-клиент на iOS с поддержкой SSH, коммитов, ветвления и пушей.

### Вариант Б: Режим "Only on Desktop" + Obsidian Sync
Если вы используете официальный Obsidian Sync для связи смартфона и десктопа, а Git хотите использовать только как архив и историю версий:
1. В настройках Obsidian Git на мобильном устройстве включите параметр:
   `Disable on this device` (Отключить на этом устройстве).
2. На десктопе в настройках плагина выберите стратегию Pull:
   `Other sync service` (предотвращает перезапись файлов при наличии Obsidian Sync).
