# Claims Schema

Один атом = одно проверяемое утверждение. Атом не содержит выводов и советов: только цитата, числа, источник, вердикт.

## Поля

| Поле | Тип | Обязательно | Смысл |
|---|---|---|---|
| `id` | `c00001` | да | Порядковый, стабильный внутри прогона |
| `article_url` | url | да | Источник; без него атом не идёт в доктрину |
| `article_title` | str | да | Для поиска и дедупа между прогонами |
| `date` | str | желательно | Дата публикации как её отдаёт API |
| `quote` | str | да | **Дословная** цитата из статьи, 40–520 символов |
| `numbers` | `["176|pct"]` | если есть | Числовые сигнатуры, см. ниже |
| `evidence` | enum | да | `first_party` / `study` / `case` / `opinion` |
| `entity` | str | да | ChatGPT, AI Mode, GPTBot, Perplexity… или `general` |
| `score` | int | да | Приоритет внутри статьи: числа +2, first_party +2, study +2, case +1, сущность +1 |
| `verdict` | enum | да | Детерминированный вердикт (см. ниже) |
| `vs_block` | `[id]` | если есть | Блоки-кандидаты от матчинга |
| `source_in_playbook` | bool | да | Статья уже цитируется доктриной |
| `verdict_llm` | enum | после слоя 3 | `NEW` / `REFINES` / `DUPLICATE` / `CONTRADICTS` |
| `block_llm` | str | после слоя 3 | Целевой блок для правки |
| `tactic` | bool | после слоя 3 | Из атома следует действие для сайта |
| `why` | str | после слоя 3 | До 15 слов: что именно нового или в чём расхождение |

## Числовые сигнатуры

Формат: `<значение>|<класс единицы>`, значение нормализовано (`1,062` → `1062`, `3.50` → `3.5`).

| Форма в тексте | Сигнатура |
|---|---|
| `200 characters` / `200 символов` | `200|chars` |
| `1,062 pages` | `1062|pages` |
| `41-day experiment` | `41|days` |
| `65%` / `65 percent` | `65|pct` |
| `4 MB` | `4|mb` |
| `8% of the time` (без единицы) | `8|bare` |

Классы, которым можно доверять при сравнении (`STRONG`): `pct, chars, pages, sites, urls, mb, kb, gb, ms, sec, days, weeks, months, years, queries, words, tokens, clicks, impressions, times, citations, referrals, searches, results, snippets, brands, products, keywords, links, domains, visits`.

Остальные слова после числа пишутся как `~word` и в матчинге не участвуют — они шумят («41-day» vs «41 dollars»).

**Зачем так.** Доктрина на русском, статьи на английском. Лексическое сравнение не работает вообще; числа с нормализованной единицей — единственный язык, общий для обоих корпусов.

## Матчинг атома к блоку

1. Отбросить значения <10 и годы 2000–2035 — они дают ложные совпадения.
2. `distinctive` = оставшиеся значения.
3. Совпадение засчитывается, если `|distinctive ∩ блок| ≥ 2` **или** (`≥1 distinctive` **и** `≥1 совпадение по классу единицы`).
4. Победитель — блок с максимальным `(distinctive, unit)`.

## Детерминированные вердикты

| Вердикт | Правило |
|---|---|
| `DUPLICATE` | Матч есть, и статья уже цитируется этим блоком |
| `REFINES` | Матч есть, статья блоком не цитируется |
| `NEW` | Матча нет |
| `REVIEW_NUMERIC` | Совпала сущность и класс единицы, но значение другое — **не противоречие**, очередь на LLM |

`REVIEW_NUMERIC` намеренно не называется `CONTRADICTS`: числа расходятся и в случаях, когда атом **подтверждает** блок (например, разные срезы одного эксперимента).

## Фильтры до извлечения

| Фильтр | Правило | Зачем |
|---|---|---|
| Topic scope | Атом обязан содержать AI-поиск: `AI Overview`, `AI Mode`, `AEO`, `GEO`, `LLM`, `ChatGPT`, `Perplexity`, `retrieval`, `citation`, `llms.txt`… | Без него в выборку лезут PPC и обычный SEO (проверено: 711 мусорных атомов против 291 релевантных) |
| Гигиена предложений | Выбросить заголовки (`#`), bullet-фрагменты (`- `, `* `), таблицы (`|`), `Published:`, `Read time:`, `Written by`, `**markdown**`, предложения короче 6 слов | Иначе в топ попадает шапка статьи и «Published: August 19, 2026 at 10:47 am» |
| Дедуп | sha1 от `[a-z0-9]` цитаты; повторы между статьями (синдикация) считаются один раз | SEL перепечатывает свои материалы |

## Типы доказательства

| Тип | Маркеры | Вес в гейте |
|---|---|---|
| `first_party` | `Google said/confirmed/documented`, `OpenAI said`, `spokesperson`, `official blog`, `patent` | A |
| `study` | `study`, `experiment`, `n=`, `we tracked/analyzed/measured`, `crawl logs`, `survey` | A при n≥100, иначе B |
| `case` | `case study`, `we saw/found`, `increase from…` | B |
| `opinion` | всё остальное | C — только в `hypotheses.md` |

Классификатор регулярный, поэтому ошибается в обе стороны: «documentation» в рекламной статье даст `first_party`. Проверять глазами всё, что идёт в тир A.
