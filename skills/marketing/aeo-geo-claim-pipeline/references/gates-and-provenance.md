# Gates & Provenance

Правила, по которым атом становится доктриной. Без них пайплайн производит ещё один пересказ — только быстрее.

## Тиры

| Тир | Условие | Куда идёт | Пометка в тексте |
|---|---|---|---|
| A | first-party (Google/OpenAI/Microsoft, документация, спикер) **или** исследование с n≥100 **или** ≥2 независимых источника об одном | тело скилла | `*Источник: [title](url), <дата>*` |
| B | одиночный кейс с цифрами, n<100 | тело скилла | `*Источник: … (выборка мала, не экстраполировать)*` |
| C | мнение, прогноз, «мы считаем» | `hypotheses.md` | не попадает в тело никогда |
| D | блока доктрины нет источника | очередь на ревизию | — |

**Тир определяется доказательством, а не тем, как уверенно звучит текст.** Ссылка на статью — это цитата, а не верификация: статья может пересказывать исследование с ошибкой (см. блок 1.2, который противоречит собственной ссылке).

## Единственное настоящее доказательство

Собственный замер на своём сайте: позиции, показы, клики, цитаты в AI-ответах до и после правки. Механика — `seo-position-monitor`. Всё остальное (включая цифры из статей) остаётся внешним утверждением с атрибуцией, пока не проверено на своём трафике.

## Политика конфликтов

| Ситуация | Действие |
|---|---|
| `CONTRADICTS`, числа из разных исследований | Не перезаписывать. В теле — оба числа с источниками и датами: «4.87% (Amsive, 2026) vs 20% (ранее в доктрине)» |
| `CONTRADICTS`, доктрина противоречит своей же ссылке | Переписать блок по первоисточнику, старый текст в changelog |
| `REVIEW_NUMERIC` | Не трогать до семантической сверки: числа расходятся и у подтверждающих атомов |
| Новее first-party, чем блок | Приоритет новому, старую запись — в историю блока |

Автозамены нет ни в одном случае: конфликт — это решение, а не merge.

## Формат write-back

Каждый блок доктрины несёт провенанс. Минимально:

```markdown
### 12.2. Meta descriptions: человек > модель
Ручные описания дали +176% CTR против ChatGPT-4, AI-сгенерированные — −21.5%.
*Источник: [Do meta descriptions matter](https://searchengineland.com/guide/do-meta-descriptions-matter), 2026-08; тир B (один эксперимент, сотни страниц)*
```

Требования:

- `source`, `date`, `tier` в каждой записи уровня A/B.
- Один блок = одно утверждение. Если атом добавляет механику, а не число — новый подпункт, не абзац в существующем.
- Строка в changelog: `2026-11-14 | 12.2 | +176% CTR ручных описаний | c00123 | tier B`.
- Механики («что делает AI-поиск») и тактики («что делать») — разные секции: механики гниют за квартал, тактики живут дольше.

## Аудит (что показал прогон 2026-11-14)

| Метрика | Значение | Следствие |
|---|---|---|
| Блоков с источником | 83 из 158 | Остальные 75 — пересказ без атрибуции |
| Блоков `B_cited_specific` | 48 | Только они проверяемы по числу |
| Покрытие корпуса | 67 из 247 статей (27%) | Доктрина построена по верхушке, не по корпусу |
| Найдено противоречий | 4 | Дрейф уже произошёл |

Приоритет ревизии: сначала 4 противоречия, потом блоки с `D_no_source`, потом тир C с цифрами (проверить, не потерялось ли число при пересказе).
