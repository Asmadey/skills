# aeo-skill — SEO / AEO / GEO для Claude Code

Набор навыков для вывода сайта в топ поисковой выдачи и в ответы LLM: ChatGPT, Google AI Overviews и AI Mode, Gemini, Claude, Perplexity, Copilot. Устроен по образцу [claude-seo](https://github.com/AgriciDaniel/claude-seo): один оркестратор, под-навыки по направлениям, агенты для параллельного аудита, скрипты проверки.

База знаний — 920 материалов Search Engine Land (700 статей и 219 гайдов, 9 мая – 9 ноября 2026) и плейбук V2. Тексты статей в навык не входят: только пересказ выводов со ссылками на оригиналы в `skills/aeo/references/sources.md`.

## Установка

```bash
bash skills/marketing/aeo-skill/install.sh
```

Скрипт копирует навыки в `~/.claude/skills` и агентов в `~/.claude/agents`; прежние версии сохраняет с пометкой `.bak`. Нужен Python 3.9+, внешних зависимостей нет. Удаление: `bash uninstall.sh`.

## Команды

| Команда | Что делает |
|---|---|
| `/aeo` | Список команд и маршрутизация |
| `/aeo audit <url>` | Полный аудит: 7 блоков, оценка 0–100, план на 90 дней |
| `/aeo technical <url>` | Видят ли сайт AI-боты: robots.txt, CDN, JavaScript, HTML, Bing, Brave |
| `/aeo content <url>` | Перестройка страницы под извлечение пассажей и цитирование |
| `/aeo entity <бренд>` | Как модели распознают бренд; консистентность данных; schema |
| `/aeo offpage <бренд>` | Карта источников, digital PR, Reddit, YouTube, возражения |
| `/aeo visibility <бренд>` | Замер по набору промптов: упоминания, цитаты, рекомендации |
| `/aeo measure` | GA4, Search Console, Bing, логи, отчётность |
| `/aeo local <бизнес>` | Локальный бизнес и сети |
| `/aeo ecommerce <url>` | Фиды, карточки, категории, фильтры |
| `/aeo refresh <url>` | Диагноз падения трафика, обновление, чистка |
| `/aeo plan <бренд>` | Стратегия, кластеры, план на 90 дней |

## Скрипты

```bash
S=~/.claude/skills/aeo/scripts
python3 $S/check_access.py https://example.com          # robots.txt и ответы сервера 15 ботам
python3 $S/page_audit.py https://example.com/page       # сырой HTML без JavaScript + разбор пассажей
python3 $S/log_bots.py /var/log/nginx/access.log        # AI-боты и переходы из ассистентов в логах
python3 $S/visibility_tracker.py report                 # журнал прогонов промптов
```

У всех есть `--help` и `--json`.

## Чем отличается от AEO-ru

| | AEO-ru (прежняя версия) | aeo-skill |
|---|---|---|
| Источники | Плейбук V2 (статьи августа 2026) | Плейбук + весь архив за май–ноябрь, 119 статей в реестре с ключами |
| Устройство | Один SKILL.md на 23 КБ | Оркестратор и 11 под-навыков, подгружаются по задаче |
| Проверка страницы | По Markdown-тексту | По сырому HTML, как его получает бот |
| llms.txt | Генератор и пункт чек-листа | Убран: по данным архива файл не влияет на видимость |
| Schema | «Обязательный рычаг» | Гигиена сущности; данные о влиянии на цитируемость приведены |
| Кеш ChatGPT | «до 30 дней» | Около 30 минут, как в исследовании |
| ChatGPT Atlas | Целевая система | Закрыт 9 августа 2026 |
| Замеры | Одиночные записи | Повторные прогоны, доли, предупреждение о малой выборке |
| Непроверяемые детали | Есть (например, «бюджет 800 мс») | Только то, что есть в источниках |

## Ограничения

- Цифры взяты из отдельных исследований 2026 года и устаревают. Перед серьёзным решением сверяйся с первоисточником по ссылке.
- Веса в методике оценки — экспертное решение, а не результат исследования.
- Скрипты шлют запросы не с адресов ботов: блокировки по IP они не увидят, для этого нужны логи.
- Замер видимости требует доступа к ассистентам. Без него навык готовит набор промптов и таблицу для ручного прогона.
