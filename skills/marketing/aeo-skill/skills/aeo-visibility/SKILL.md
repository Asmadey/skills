# Замер AI-видимости

Ответы моделей вероятностные. Одиночный прогон — это монета: разброс на одинаковый промпт 10–34%, после трёх прогонов сохраняется малая часть цитат, за месяц 79% пар «вопрос–ассистент» меняют список брендов [S038, S039]. Поэтому меряем доли и динамику.

## 1. Набор промптов

Собери 20–50 промптов по `../aeo/references/prompt-set.md`:

- Разбивка по этапам: проблема, выбор, сравнение, проверка, действие. Бренд обычно виден в брендовых и сравнительных и пропадает на этапе проблемы [S087].
- Формулировки — из CRM, поддержки, отзывов, форумов. Сгенерированные моделью промпты не доказывают, что так спрашивают люди.
- Нейтральные, позитивные и негативные варианты [S040].
- Язык: один для сравнимости рынков, локальный — отдельным набором [S041].
- Набор фиксируется. Меняешь формулировку — начинаешь новый ряд.

## 2. Протокол прогона

- Чистая сессия без истории и персонализации; фиксируй режим (быстрый или с рассуждением) и включён ли поиск. Режим рассуждения ChatGPT — фактически другой движок: меняются три четверти источников [S013].
- 3–5 прогонов на промпт и движок, раз в неделю в один день.
- Движки по приоритету аудитории: ChatGPT, Google AI Overviews и AI Mode, Gemini, Claude, Perplexity, Copilot. Совпадение источников между ними малое, один движок даёт искажённую картину.
- Для Google AIO дополнительно проверь, по каким запросам блок появляется, включая брендовые [S060].

Если у тебя есть инструмент для запросов к ассистентам — используй. Если нет, выдай пользователю таблицу для ручного прогона; не имитируй ответы моделей по памяти. Ответы API отличаются от продукта: совпадение брендов около четверти.

## 3. Запись

```bash
python3 ../aeo/scripts/visibility_tracker.py init --brand "<бренд>"
python3 ../aeo/scripts/visibility_tracker.py add --prompt "..." --engine chatgpt --stage выбор \
  --mention y --cited n --position 3 --recommended n --sentiment нейтрально --accurate y \
  --rivals "A;B" --sources "g2.com;reddit.com"
python3 ../aeo/scripts/visibility_tracker.py report
```

## 4. Четыре исхода [S023, S091]

| Исход | Смысл | Действие |
|---|---|---|
| Упоминание и цитата | Цель | Удерживать, обновлять страницу |
| Только цитата | Контент работает на чужое имя | Привязка бренда к фактам (`aeo-content`) |
| Только упоминание | Модель знает бренд по сторонним источникам | Дать цитируемую страницу по теме |
| Ничего | Нет в наборе рассмотрения | Сущность и сторонний след |

Для каждой «только цитаты» диагноз на трёх уровнях: предложение (назван ли бренд рядом с фактом), страница (чья это тема), сущность (связывают ли бренд с темой вне сайта).

## 5. Метрики

| Метрика | Как считать |
|---|---|
| Доля появлений | Прогоны с упоминанием / все прогоны, по движку и этапу |
| Доля рекомендаций | Где бренд рекомендован, а не перечислен |
| Позиция | Первый, середина, последний |
| Доля цитат без бренда | «Только цитата» / все цитаты |
| Точность | Доля ответов без фактических ошибок |
| Тональность и повторяющиеся возражения | Текстом, с источниками |
| Соседи | Кто назван вместо бренда и рядом |
| Устойчивость | Доля пар, где бренд есть во всех прогонах |

Общая «доля голоса» одним числом скрывает картину: показывай долю упоминаний, долю рекомендаций и то, как бренд описан.

## 6. Чтение результатов

- Шорт-лист — это 5–10 имён. Цель — войти в него по своим сценариям, а не «быть везде».
- Смотри, для чего модель считает бренд лучшим: аудитория и сценарий. Не все места в списке равны [S085].
- Сдвиг за неделю — шум. Сдвиг, который держится три-четыре недели на нескольких движках, — сигнал.
- Резкая смена источников при тех же промптах — вероятно, сменился конвейер поиска движка [S012].
- Сопоставляй с брендовым спросом в Search Console и прямым трафиком (`aeo-measure`).

## Результат

Отчёт: набор промптов, протокол, таблица долей по движкам и этапам, исходы, соседи, источники, ошибки в фактах с цитатами, три вывода и что делать. Обязательно укажи число прогонов и дату: без них цифры не интерпретируются.
