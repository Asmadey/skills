# AEO: оркестратор SEO / AEO / GEO

Навык построен на 920 материалах Search Engine Land за май–ноябрь 2026. Каждое правило опирается на исследование из реестра `references/sources.md` (ключи `Sxxx`). Цифры — ориентиры из отдельных исследований, а не законы: при выдаче рекомендаций называй источник и размер выборки.

## Маршрутизация

| Команда | Под-навык | Когда |
|---|---|---|
| `/aeo audit <url>` | `aeo-audit` | Полный аудит с оценкой 0–100 и планом |
| `/aeo technical <url>` | `aeo-technical` | Видят ли AI-боты сайт: robots, JS, HTML, размер, Bing |
| `/aeo content <url\|файл>` | `aeo-content` | Переписать страницу под извлечение пассажей |
| `/aeo entity <бренд>` | `aeo-entity` | Как AI понимает бренд: сущность, schema, консистентность |
| `/aeo offpage <бренд>` | `aeo-offpage` | Сторонние упоминания, digital PR, Reddit, YouTube, 90 дней |
| `/aeo visibility <бренд>` | `aeo-visibility` | Замер видимости по набору промптов |
| `/aeo measure` | `aeo-measure` | GA4, GSC, Bing, логи: что считать и как |
| `/aeo local <бизнес>` | `aeo-local` | Локальный бизнес и сети |
| `/aeo ecommerce <url>` | `aeo-ecommerce` | Интернет-магазин, фиды, категории |
| `/aeo refresh <url>` | `aeo-refresh` | Обновление, угасание контента, чистка |
| `/aeo plan <бренд>` | `aeo-plan` | Стратегия и дорожная карта на 90 дней |

Без аргументов — покажи эту таблицу и спроси URL или бренд. Если запрос не укладывается в одну команду, начни с `aeo-audit`.

## Порядок работы для любой команды

1. **Определи тип бизнеса**: SaaS/B2B, ecommerce, локальный, издатель, YMYL. От него зависят веса и чек-листы (`references/scoring.md`).
2. **Собери факты, прежде чем советовать.** Запусти скрипты из `scripts/` (ниже), получи сырой HTML и robots.txt. Не делай выводов о сайте по памяти.
3. **Отдели проверенное от непроверенного.** То, что не удалось проверить (GSC, логи, Bing Webmaster без доступа), помечай `НЕ ПРОВЕРЕНО` и говори, что нужно для проверки. Не выдумывай статус sitemap, индексации, профилей в каталогах [S028].
4. **Каждая рекомендация** содержит: что сделать, на какой странице, почему (ключ источника), как проверить результат и через какой срок.
5. **Приоритизация**: сначала доступность, потом доверие, потом контент [S042]. Оптимизировать текст на сайте, который боты не могут прочитать, бессмысленно.

## Семь принципов (сводка доказательной базы)

1. **AI-боты не исполняют JavaScript.** Контент, ссылки и schema должны быть в исходном HTML [S001, S006, S008].
2. **Единица работы — пассаж, а не страница.** Ответ в первом предложении блока, блок понятен без контекста [S003, S016].
3. **Бренд выбирают по сторонним источникам.** Собственный сайт объясняет, кто вы; рекомендуют вас на основании чужих страниц [S025, S026].
4. **Цитата не равна упоминанию, упоминание не равно рекомендации.** Считай их отдельно [S022, S024, S019].
5. **Каждый движок — отдельный рынок.** Источники у ChatGPT, Gemini, Claude и Google почти не пересекаются [S012, S013, S014].
6. **Один прогон промпта ничего не значит.** Нужны повторы и динамика [S038, S039].
7. **AI-видимость — канал бренда, а не трафика.** Реферальный трафик мал, влияние на спрос велико и плохо атрибутируется [S054, S008].

Подробности и цифры: `references/evidence-base.md`. Устройство движков: `references/engines.md`. Что не работает: `references/myths.md`.

## Скрипты

Стандартная библиотека Python 3.9+, без зависимостей. Путь — относительно папки этого навыка.

```bash
python3 scripts/check_access.py https://example.com            # robots.txt и ответы сервера для AI-ботов
python3 scripts/page_audit.py https://example.com/page         # сырой HTML глазами AI-бота + разбор пассажей
python3 scripts/page_audit.py --file page.html --json          # то же для локального файла
python3 scripts/log_bots.py access.log                         # активность AI-ботов в логах сервера
python3 scripts/visibility_tracker.py init|add|report ...      # журнал прогонов промптов
```

Если сеть из оболочки недоступна, получи HTML другим доступным способом (WebFetch, браузер, файл от пользователя) и передай его через `--file`.

## Формат результата

- Короткий вывод в начале: оценка, три главные проблемы, три первых действия.
- Таблица находок: `Приоритет | Находка | Доказательство | Действие | Источник`.
- Приоритеты: **Критично** (боты не видят контент), **Высокий** (бренд не извлекается или не подтверждается), **Средний**, **Низкий**.
- В конце — список непроверенного и что нужно от пользователя.
- Отчёты сохраняй в `aeo-reports/<домен>-<дата>.md`, если пользователь не просил иначе.

## Чего навык не делает

- Не обещает позиции и попадание в ответы: выдача LLM вероятностная.
- Не рекомендует покупку упоминаний, сети сайтов, астротурфинг на Reddit, фальшивых авторов и отзывы [S037, S069].
- Не советует llms.txt как рычаг видимости [S008, S009].
- Не генерирует массовый контент без проверки человеком [S068].
