# Наборы промптов для замеров

Правила составления [S038, S039, S040, S041, S087]:

- 20–50 промптов, разбитых по этапам воронки. Общий процент видимости без разбивки скрывает, где бренд выпадает.
- Формулируй так, как пишет покупатель: длинно, с ситуацией и ограничениями. Источники формулировок — CRM, поддержка, отзывы, форумы, а не генерация моделью.
- Включай нейтральные, позитивные и негативные формулировки: негативные сдвигают тональность сильнее всего.
- Один язык трекинга на все рынки ради сравнимости; локальный язык — отдельным набором.
- Каждый промпт прогоняй минимум 3–5 раз на движок, в чистой сессии, и повторяй еженедельно. Сообщай долю появлений, а не «есть/нет».

Подставь: `{бренд}`, `{категория}`, `{конкурент}`, `{задача}`, `{аудитория}`, `{город}`.

## 1. Распознавание сущности (без контекста) [S029]

- Что такое {бренд}?
- Чем занимается {бренд}?
- Расскажи всё, что знаешь о {бренд}.
- Какая это компания — {бренд}?

Смотри: одна ли сущность во всех ответах, просит ли модель уточнить, смешивает ли свойства разных компаний.

## 2. Категоризация

- К какой категории продуктов относится {бренд}?
- Для кого {бренд} и для кого он не подходит?
- С кем конкурирует {бренд}?

## 3. Осознание проблемы (бренд не назван)

- Как решить {задача}, если {ограничение аудитории}?
- Почему возникает {проблема} и что с этим делают?

## 4. Выбор решения (бренд не назван)

- Какие {категория} лучше всего подходят для {аудитория}?
- Посоветуй {категория} с {требование} до {бюджет}.
- Какие бренды известны {свойство, на котором строится позиционирование}?
- Лучшие {категория} в {город}.

## 5. Сравнение

- {бренд} или {конкурент}: что выбрать для {задача}?
- Альтернативы {конкурент}.
- В чём разница между {бренд} и {конкурент} по цене, интеграциям, поддержке?

## 6. Проверка и возражения

- Стоит ли {бренд} своих денег?
- Какие недостатки у {бренд}?
- Отзывы о {бренд}: на что жалуются?
- Надёжен ли {бренд}?

## 7. Действие и логистика

- Сколько стоит {бренд}? Есть ли пробный период?
- Как подключить {бренд} к {система}?
- Часы работы, адрес, телефон {бренд} в {город}.

## 8. Продолжение диалога [S118]

После каждого ответа задай один уточняющий вопрос из пяти типов:

- Уточнение: «Что это значит?»
- Ограничение: «А если бюджет небольшой?»
- Сравнение: «Чем вариант А отличается от Б?»
- Проверка: «Какие доказательства это подтверждают?»
- Действие: «Что мне сделать дальше?»

## Что записывать по каждому прогону

| Поле | Значения |
|---|---|
| Упоминание | да / нет |
| Позиция в списке | первый, середина, последний, нет |
| Цитата (ссылка на ваш URL) | да / нет |
| Исход | оба, только цитата, только упоминание, ничего |
| Рекомендация | рекомендован, перечислен, противопоставлен |
| Тональность | позитив, нейтрально, негатив |
| Точность фактов | верно / ошибка (какая) |
| Источники ответа | домены и URL |
| Кто назван вместо вас | бренды |

Журнал ведёт `../scripts/visibility_tracker.py`.

## Аудит позиционирования (0–10) [S031]

Сначала запиши «истину» по опубликованным материалам. Затем оцени ответ каждой модели по пяти измерениям, 0–2 балла:

1. Категория названа верно.
2. Целевой клиент назван верно.
3. Ценностное предложение передано.
4. Отличия от конкурентов указаны.
5. Доказательства приведены и проверяемы.

Типичный провал: модель знает, что делает бренд, но не знает, для кого он. Исправляется явным указанием аудитории на сайте и в сторонних описаниях.
