# Контент под извлечение

Модели извлекают отдельные фрагменты и оценивают каждое предложение как самостоятельную единицу [S016]. Задача — сделать так, чтобы фрагмент, вырванный из страницы, оставался верным, понятным и называл бренд.

## 1. Диагностика

```bash
python3 ../aeo/scripts/page_audit.py <url|--file page.html> --brand "<бренд>"
```

Ориентиры: 85% секций без замечаний, ответ в первом предложении, медиана пассажа около 100–150 слов, не меньше трети заголовков — вопросы [S003].

## 2. Верх страницы

- **Title** — самодостаточное предложение: предмет, для кого, чем отличается. Для запросов о рейтингах и свежих данных добавь год [S002, S014].
- **H1 и первые 200 символов**: сразу ключевая мысль. Дату, автора, крошки, оглавление — ниже [S002].
- **Ответная капсула**: 40–60 слов прямого ответа на главный вопрос страницы, чистой прозой, без ссылок внутри [S017, S016].

## 3. Формула секции [S016]

1. Заголовок H2/H3, понятный вне страницы: тема, намерение, охват. Не «Обзор» и не «Выводы».
2. Прямой ответ в первом предложении (всего 40–60 слов).
3. Один-два предложения контекста.
4. Доказательство в извлекаемой форме: таблица, нумерованный список, цифра с источником.
5. История, пример, голос бренда — после этого блока.

Два теста для каждого предложения в середине страницы:

- **Изоляция**: понятно ли оно без соседей?
- **Однозначность**: ясно ли, о ком и о чём речь? Заменяй «он», «это», «данный сервис» на название.

## 4. Запрещённые обороты

«Как упоминалось выше», «в этой статье мы рассмотрим», «давайте разберёмся», «не секрет, что». Пустые превосходные степени («лучший в городе», «мирового уровня») хуже отсутствия утверждения: их нельзя проверить [S027].

## 5. Привязка бренда к фактам

До 75% ответов цитируют страницу, не называя бренд [S022]. Приёмы:

| Было | Стало |
|---|---|
| «Наш анализ показал, что 40% цитат…» | «Исследование Acme Citation Study 2026 показало, что 40% цитат…» |
| «Сервис обрабатывает до 45 000 запросов в секунду» | «Acme Data Core обрабатывает до 45 000 запросов в секунду» |
| «Мы сократили издержки на 40%» | «Acme сократила издержки клиента N на 40% за шесть месяцев при базе 1 200 обращений в месяц» |

- Строй предложения по схеме «сущность → действие → число».
- Давай исследованиям, индексам и методикам имя с брендом.
- На информационных страницах («что такое», «как работает») бренд называют редко — 18% при цитировании 89% [S023]. Добавляй собственный пример или данные, а не только определение.

## 6. Форматы, которые цитируют

- **Сравнительные таблицы в HTML** с конкретными значениями: цены, сроки, характеристики [S004].
- **Листиклы и сравнения**: половина самых цитируемых URL. Собственный рейтинг с собой на первом месте вредит рекомендации; включай конкурентов, критерии и для кого каждый вариант [S018, S019, S020].
- **Оригинальные данные**: измеримое сравнение названных объектов, собственные данные, описание метода по шагам, заголовки-ответы, ссылка на сырые данные [S021].
- **Инструменты**: калькулятор, подборщик, проверка — с понятным названием и ответом на конкретный вопрос [S017].
- **FAQ из реальных вопросов**: поддержка, продажи, отзывы, Reddit, объёмы промптов.
- Объём цитируемых страниц чаще 1 000–2 000 слов, предложения около 18 слов [S018]. Длинные «полные руководства» уступают набору сильных секций.

## 7. Покрытие подзапросов

1. Выпиши 15–40 подзапросов (fan-out) к теме: определения, сравнения, цены, ограничения, «для кого», шаги.
2. Добавь пять типов следующего вопроса: уточнение, ограничение, сравнение, проверка, действие [S118].
3. Каждому важному подзапросу — секция с ответом. Страница, ранжирующаяся ещё и по подзапросам, цитируется заметно чаще [S062].
4. Новую страницу создавай, только если запрос проходит тест независимости: нет своей страницы в выдаче, выдача слабо пересекается с соседним запросом, тема самодостаточна [S096].

## 8. Доверие

- Реальный автор с проверяемым профилем; вымышленные авторы — признак низкого качества [S069].
- Дата обновления, отражающая настоящую правку.
- Каждое число — с источником или методом.
- AI-черновик проверяет человек: факты, цифры, ссылки [S068].
- Опыт из первых рук: что делали, что измерили, что пошло не так. Это единственное, что модель не может сгенерировать сама.
- Открой сравнения, цены, кейсы и обучающие материалы; форму оставь для персонализированного [S047].

## 9. Изображения и видео

- Содержательные картинки (графики, схемы, скриншоты, фото продукта) с alt, описывающим факт. То, что написано на инфографике, продублируй текстом [S094].
- Видео: развёрнутое описание и таймкоды на YouTube; ссылайся на конкретные моменты как на доказательства [S036].

## Результат

1. Таблица «секция → проблема → исправление».
2. Переписанный текст: новый title, капсула, секции по формуле.
3. Список того, чего не хватает и что может дать только заказчик: данные, цитаты экспертов, цены, кейсы.

Не меняй URL, работающий title и смысл утверждений без подтверждения пользователя. Факты не придумывай: где нужна цифра, оставь пометку `[НУЖНЫ ДАННЫЕ: …]`.
