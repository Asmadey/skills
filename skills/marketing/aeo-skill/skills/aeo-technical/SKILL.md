# Техническая доступность

Правило порядка: пока этот блок не пройден, работа над контентом не даёт эффекта [S042, S006].

## 1. Запусти проверки

```bash
python3 ../aeo/scripts/check_access.py <url>
python3 ../aeo/scripts/page_audit.py <url>
python3 ../aeo/scripts/log_bots.py <access.log>     # если есть логи
```

## 2. Чек-лист

### Критично

| Проверка | Как проверить | Норма | Источник |
|---|---|---|---|
| robots.txt не закрывает поисковых и пользовательских ботов | `check_access.py` | OAI-SearchBot, ChatGPT-User, Claude-SearchBot, Claude-User, PerplexityBot, Googlebot, Bingbot разрешены | S006 |
| CDN и WAF не блокируют ботов | Ответ 200 на запрос с UA бота; настройки Cloudflare (блокировка AI-краулеров включена по умолчанию) | Нет 403/429/503 | S042, S007 |
| Контент есть в сыром HTML | `page_audit.py`: слова в сыром HTML | Основной текст, цены, характеристики присутствуют без JS | S001, S008 |
| Внутренние ссылки — обычные `<a href>` | Ссылок в сыром HTML > 5; навигация не строится скриптом | Все важные страницы достижимы по HTML-ссылкам | S001 |
| Нет стены перед контентом | Открой без cookie: языковой селектор, выбор города, cookie-стена, логин | Контент виден сразу | S027, S072 |
| Размер HTML | `page_audit.py` | Меньше 4 МБ | S002 |
| Нет случайного `noindex` и конфликта с robots.txt | meta robots, заголовок X-Robots-Tag | Страница, закрытая в robots.txt, не может сообщить о noindex: открой сканирование и оставь noindex в HTML | S074 |

### Высокий приоритет

| Проверка | Действие | Источник |
|---|---|---|
| Индексация в Bing | Bing Webmaster Tools, запрос `site:` в Bing; подключи IndexNow | S002 |
| Позиции в Brave Search | Проверь главные запросы в search.brave.com: оттуда берёт результаты Claude | S014 |
| Sitemap | Указан в robots.txt, отдаёт 200, содержит только канонические URL | S001 |
| Один канонический домен | 301 со всех вариантов (www, http, старые домены); одинаковые canonical | S005, S074 |
| Цены и условия в HTML | Не в PDF, не за формой, не в скрипте | S046, S047 |
| Schema в серверном HTML | JSON-LD отдаётся сервером, а не вставляется тег-менеджером | S006 |
| Мягкие 404 | Страницы «ничего не найдено» с ответом 200; ищи в логах по размеру ответа | S075 |
| Pop-up и баннеры | Не закрывают контент, не сдвигают вёрстку, грузятся асинхронно. Боты ничего не закрывают и не скроллят | S072, S073 |

### Средний приоритет

- Один H1; сразу после него — ключевая мысль, без дат, крошек и оглавления [S002].
- Семантические элементы `main`, `article`, `nav`; у кнопок и ссылок понятные имена; alt у содержательных картинок [S077].
- Core Web Vitals: чинить на страницах с выручкой, не гоняться за мелкими колебаниями по всему сайту [S111].
- Пагинация обычными ссылками; фильтры каталога не плодят индексируемые дубли [S112].
- Для сайтов, собранных AI-инструментами: проверь, что новые блоки не ушли в клиентский рендеринг, что bot-защита не режет Googlebot, что формы не принимают спам [S007].

## 3. Сайты на JS-фреймворках

1. Сравни «Просмотр кода страницы» и то, что видно в браузере. Чего нет в коде — того нет для AI.
2. Решения по убыванию надёжности: SSG → SSR → гибрид → статический запасной HTML для ключевых страниц.
3. Динамический рендеринг только для ботов — устаревающий путь; не рекомендуй его как основное решение.
4. После исправления боты сами быстро не вернутся: отправь URL через IndexNow и sitemap [S001].

## 4. Логи

- ChatGPT-User, Claude-User, Perplexity-User — чтение страниц по запросам людей. Список таких страниц показывает, о чём вас спрашивают.
- Поисковые боты есть, пользовательских нет — контент находят, но не выбирают.
- Много 403/429 у одного бота — блокировка на уровне инфраструктуры.
- Храни логи не меньше 90 дней: по ним видны миграции и сбои сканирования [S075].

## 5. Что не чинить

Не все замечания краулера стоят работы [S097, S111]. Отложи: каждый 404 на сайте, alt у декоративных картинок, «неправильные» уровни заголовков без влияния на смысл, расширение schema ради полноты. Сортируй по корзинам: чинить сейчас, чинить скоро, наблюдать, игнорировать.

## 6. Порядок внедрения

Доступ ботам → сырой HTML и ссылки → индексация (Bing, sitemap, canonical) → метаданные и первые 200 символов → всё остальное. В описанном кейсе рост пошёл только после правки метаданных, хотя сканирование починили раньше [S108].
