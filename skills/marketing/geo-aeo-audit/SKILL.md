# GEO / AEO audit

Проверка сайта по машинно-проверяемой части GEO/AEO: то, что можно подтвердить
запросом к сайту. Скрипт не рассуждает и не вызывает LLM — он смотрит, что реально
отдаётся в ответ на запрос без исполнения JavaScript, то есть глазами AI-краулера.

## When to Use

Загружать, когда нужно:

- понять, почему сайт не появляется в ответах ChatGPT, Perplexity, AI Overviews или Алисы;
- получить список правок, отсортированный по отдаче, а не 200 пунктов из Lighthouse;
- проверить страницу или сайт после смены шаблона, переезда или редизайна;
- поставить регулярный мониторинг деградаций.

Не подходит: производительность и Core Web Vitals (это `seo-audit`), тексты статей
(это `seo-article-standard`), замер позиций (это `seo-position-monitor`).

## Quick start

```bash
python3 scripts/geo_audit.py --site https://example.com
python3 scripts/geo_audit.py --site https://example.com --limit 5     # быстрая проверка
python3 scripts/geo_audit.py --site https://example.com --json        # машинный вывод
python3 scripts/geo_audit.py --site https://example.com --out-dir ./geo-audit
```

Скрипт берёт `robots.txt`, `sitemap.xml`, обходит все URL и печатает три блока:
находки по severity, «что делать» по убыванию отдачи, таблицу по страницам.
Снимок сохраняется в `~/.geo-audit/<host>/audit-<дата>_<время>.json` и `latest.json`
(каталог меняется через `--out-dir` или переменную `GEO_AUDIT_DIR`).

Оценка = 100 минус штрафы. Штраф проверки взвешен по **доле затронутых страниц**
(critical 10, high 5, medium 2, low 1), поэтому одна проблема на 25 страницах не топит
балл, а системная — топит.

## Что проверяется

| Проверка | Что значит | Техника плейбука |
|---|---|---|
| AI-боты не закрыты в robots.txt | закрытый бот это нулевая видимость | 1.6 |
| текст есть в raw HTML, а не только после JS | AI-краулеры не исполняют JavaScript | 1.1, 1.12 |
| страница меньше 4 МБ | большее LLM отвергает целиком | 1.5 |
| страницы из sitemap достижимы за 2 клика по HTML-ссылкам | сироты не обходятся | 1.2 |
| один h1, canonical на себя, meta description, lang | базовая машинная разметка | 1.11, 13.2 |
| после h1 идёт ответ, а не дата или оглавление | бюджет первых 200 символов | 1.3, 2.4 |
| часть h2 сформулирована вопросом | пассажи-вопросы переиспользуются чаще | 2.1, 2.10 |
| внутренние ссылки в HTML, перелинковка кластера | обход и связи между страницами | 1.2, 2.7 |
| JSON-LD: тип страницы, Organization с sameAs, dateModified | представление и свежесть | 5.1, 4.2, 4.6 |
| alt у изображений, webp/avif/svg | картиночный поиск и скорость | 14.2, 1.9 |
| HTML-таблица на сравнительных страницах | таблицы цитируются чаще текста | 2.6 |
| noindex в HTML не конфликтует с robots.txt | иначе страница не индексируется | 1.13 |

Полная карта «проверка → как чинить» в [`references/checks-map.md`](references/checks-map.md).

## Validation Gates

- **Перед выводами.** Скрипт должен реально сходить на сайт: если в отчёте 0 страниц или
  все `HTTP 0`, это сеть или WAF, а не «сайт идеален».
- **Оценка без контекста не значит ничего.** 98/100 при закрытом AI-боте или мёртвом
  Bing-индексе — это всё ещё провал. Смотреть находки, а не балл.
- **Разделять системное и косметику.** `critical`/`high` чинятся пачкой в шаблоне,
  `low` только если правится в том же файле.
- **Сравнивать только с предыдущим снимком** из того же каталога: между прогонами
  меняется и сайт, и набор страниц.
- **Проверять на двух типах сайтов.** На SPA индикатор `raw_text` должен сработать;
  если он молчит на client-rendered сайте, значит скрипт читает не то, что отдаёт сервер.

## Что скрипт НЕ проверяет

Требует внешних данных, делается руками:

1. **Индексация в Bing** — без неё нет ChatGPT (87% цитат SearchGPT совпадают с топом Bing).
2. **AI-цитирование и ghost citations** — 40% цитат не называют бренд; нужен прогон
   money-запросов в ChatGPT, Perplexity и Gemini с подсчётом упоминаний.
3. **Кроулинг AI-ботов** — только по server-логам: `ChatGPT-User` не несёт `utm_source`.
4. **Grounding Drift** — одинаковые запросы дают разные источники примерно в 60% случаев,
   один замер ничего не доказывает.
5. **Покрытие кластеров спроса** — сверять с Wordstat и Search Console, не с сайтом.

## Грабли

- **Raw HTML ≠ отрендеренная страница.** Скрипт намеренно не исполняет JS: если текст
  появляется только в браузере, для AI-бота страницы нет.
- **`alt=""` у декоративных картинок это норма.** «Нет атрибута alt» (medium) и «alt пустой»
  (low) разделены, чтобы не чинили иконки ради балла.
- **`llms.txt` не влияет на ранжирование** и Google его не использует. Файл можно держать,
  в отчёт он не входит.
- **Не менять URL slug и работающий title ради аудита**: полное переписывание даёт
  самовольный демоушн.
- **Разметка не двигает позиции.** Яндекс: Schema.org «напрямую не влияет на ранжирование».
  Google удалил FAQ rich results в мае 2026. Разметка нужна для представления и извлечения,
  а не для «буста».
- **Сайт за Cloudflare отвечает 403 на запросы без браузерной подписи.** Скрипт ходит с
  браузерным User-Agent; если и это блокируется, проверять вручную.
