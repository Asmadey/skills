# 🎬 /brag — Генератор лаунч-видео для проектов

**You built it. Now brag.**

Автоматизированный навык, превращающий ваш текущий проект, веб-сайт или репозиторий в короткое, стильное лаунч-видео (15–25 сек) с динамичной анимацией, музыкой, синхронизацией по битам (beat-sync) и готовым промо-текстом для публикации.

---

## 🧭 Стартовая точка и режимы работы

Навык предоставляет две реализации под разные сценарии:

1. **[/brag (Hyperframes Mode)](skills/brag/SKILL.md)** — классический высокополированный пайплайн с библиотекой саундтреков, звуковых эффектов (интерфейсные клики, карточки, импакты) и опциональной озвучкой (voiceover).
2. **[/brag-slim (Zero-Dependency Mode)](skills/brag-slim/SKILL.md)** — автономный легковесный режим, генерирующий видео локально силами модели (HTML/CSS/Canvas + Puppeteer/Playwright + FFmpeg) без внешних сервисов.

---

## ⚡ Быстрый запуск

Запустите команду из корня проекта:
```bash
/brag
```

### Параметры и флаги:

| Флаг | Значения | Описание |
|---|---|---|
| `--tone` | `default`, `polished`, `yc-parody`, `chaotic`, `deadpan`, `cinematic`, `app-store` | Тональность и характер видео |
| `--format` | `landscape` (16:9), `vertical` (9:16), `square` (1:1) | Формат и соотношение сторон (по умолчанию `landscape`) |
| `--duration` | Число в секундах (например, `20`) | Длина ролика (по умолчанию 15–25 сек) |
| `--voice` | флаг | Включить озвучку диктором |
| `--no-music` | флаг | Отключить фоновую музыку |
| `--no-sfx` | флаг | Отключить звуковые эффекты интерфейса |
| `--slim` | флаг | Принудительно использовать автономный режим `/brag-slim` |

## 🔄 Как устроен процесс

1. **Анализ кодовой базы (Inspect):**
   - Читает структуру, цветовую палитру (CSS/Tailwind токены), шрифты, скриншоты, логотипы и ключевую функциональность.
2. **Креативный бриф и план (Plan):**
   - Создает `brag-plan.md`: угол подачи, визуальный хук, 2–3 ключевых преимущества, сценарий по сценам с точным таймингом под музыкальный темп (BPM).
3. **Композиция и анимация (Compose):**
   - Рендерит живой интерфейс с акцентом на действие пользователя (entry → action → result).
4. **Рендеринг и выдача (Deliver):**
   - Формирует `brag.mp4` с постером `brag.jpg` на первом кадре.
   - Создает `share-copy.txt` — готовый текст для анонса в соцсетях без корпоративного пафоса.
