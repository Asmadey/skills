# Frontend Design

## 1. When to use
- **Initial Prototyping**: When starting a new UI feature and needing a strong visual direction.
- **Brand Identity**: To create interfaces that feel "premium" and unique rather than standard boilerplates.
- **Complex UI**: Dashboard design, SaaS landing pages, interactive settings panels.

## 2. Validation & Prerequisites
- [ ] Framework (React, Next.js, etc.) should be initialized.
- [ ] UI Library (Tailwind, Radix) version should be specified in project context.

## 3. Workflow (Checklist)
- [ ] Step 1: Define aesthetic goal (e.g., "minimalist", "bold", "glassmorphism").
- [ ] Step 2: Request UI component with specific personality.
- [ ] Step 3: Refine animations and micro-interactions.

## 4. Instructions (Degrees of Freedom)
### Heuristics (High Freedom)
- Push for distinctive typography and color palettes.
- Avoid browser defaults; use modern CSS techniques (Grid, Flexbox, Transitions).

## 5. Integration with Antigravity
Works in tandem with `taste-skill`. While `taste-skill` handles high-end implementation and engineering, `frontend-design` provides the "creative spark" and distinctive UI logic. Use this skill when a task involves "designing" from scratch.
