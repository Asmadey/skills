# Database Integration

SQLx and Diesel patterns for Rust database access.

---

## SQLx (Recommended)

### Setup

```toml
[dependencies]
sqlx = { version = "0.7", features = ["runtime-tokio", "postgres", "macros"] }
tokio = { version = "1", features = ["full"] }
```

### Connection Pool

```rust
use sqlx::postgres::PgPoolOptions;

#[tokio::main]
async fn main() -> Result<(), sqlx::Error> {
    let pool = PgPoolOptions::new()
        .max_connections(5)
        .connect("postgres://user:pass@localhost/db")
        .await?;
    
    Ok(())
}
```

### Compile-Time Checked Queries

```rust
// Requires DATABASE_URL env var for compilation
#[derive(sqlx::FromRow)]
struct User {
    id: i64,
    name: String,
    email: String,
}

async fn get_user(pool: &PgPool, id: i64) -> Result<User, sqlx::Error> {
    sqlx::query_as!(
        User,
        "SELECT id, name, email FROM users WHERE id = $1",
        id
    )
    .fetch_one(pool)
    .await
}

async fn list_users(pool: &PgPool) -> Result<Vec<User>, sqlx::Error> {
    sqlx::query_as!(User, "SELECT id, name, email FROM users")
        .fetch_all(pool)
        .await
}
```

### Dynamic Queries

```rust
async fn search_users(pool: &PgPool, name: Option<&str>) -> Result<Vec<User>, sqlx::Error> {
    let mut query = sqlx::QueryBuilder::new("SELECT id, name, email FROM users WHERE 1=1");
    
    if let Some(name) = name {
        query.push(" AND name ILIKE ");
        query.push_bind(format!("%{}%", name));
    }
    
    query.build_query_as::<User>()
        .fetch_all(pool)
        .await
}
```

### Transactions

```rust
async fn transfer(pool: &PgPool, from: i64, to: i64, amount: i64) -> Result<(), sqlx::Error> {
    let mut tx = pool.begin().await?;
    
    sqlx::query!("UPDATE accounts SET balance = balance - $1 WHERE id = $2", amount, from)
        .execute(&mut *tx)
        .await?;
    
    sqlx::query!("UPDATE accounts SET balance = balance + $1 WHERE id = $2", amount, to)
        .execute(&mut *tx)
        .await?;
    
    tx.commit().await?;
    Ok(())
}
```

### Migrations

```bash
# Install CLI
cargo install sqlx-cli

# Create migration
sqlx migrate add create_users

# Run migrations
sqlx migrate run

# Prepare for offline compilation
cargo sqlx prepare
```

```sql
-- migrations/20240101_create_users.sql
CREATE TABLE users (
    id BIGSERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    created_at TIMESTAMPTZ DEFAULT NOW()
);
```

## Diesel (Alternative)

### Setup

```toml
[dependencies]
diesel = { version = "2.1", features = ["postgres", "r2d2"] }
dotenvy = "0.15"
```

### Schema

```rust
// src/schema.rs (generated by diesel CLI)
diesel::table! {
    users (id) {
        id -> Int8,
        name -> Varchar,
        email -> Varchar,
    }
}
```

### Models

```rust
use diesel::prelude::*;

#[derive(Queryable, Selectable)]
#[diesel(table_name = crate::schema::users)]
pub struct User {
    pub id: i64,
    pub name: String,
    pub email: String,
}

#[derive(Insertable)]
#[diesel(table_name = crate::schema::users)]
pub struct NewUser<'a> {
    pub name: &'a str,
    pub email: &'a str,
}
```

### CRUD Operations

```rust
use diesel::prelude::*;
use crate::schema::users;

fn create_user(conn: &mut PgConnection, name: &str, email: &str) -> User {
    let new_user = NewUser { name, email };
    
    diesel::insert_into(users::table)
        .values(&new_user)
        .returning(User::as_returning())
        .get_result(conn)
        .expect("Error saving user")
}

fn get_user(conn: &mut PgConnection, user_id: i64) -> Option<User> {
    users::table
        .find(user_id)
        .select(User::as_select())
        .first(conn)
        .optional()
        .expect("Error loading user")
}

fn update_user(conn: &mut PgConnection, user_id: i64, new_name: &str) -> User {
    diesel::update(users::table.find(user_id))
        .set(users::name.eq(new_name))
        .returning(User::as_returning())
        .get_result(conn)
        .expect("Error updating user")
}

fn delete_user(conn: &mut PgConnection, user_id: i64) -> usize {
    diesel::delete(users::table.find(user_id))
        .execute(conn)
        .expect("Error deleting user")
}
```

## SQLx vs Diesel

| Feature | SQLx | Diesel |
|---------|------|--------|
| Async | ✅ Native | ❌ Sync only |
| Compile-time checks | ✅ Via macros | ✅ Via schema |
| Schema management | Manual SQL | Generated code |
| Learning curve | Lower | Higher |
| Type safety | Query-level | Schema-level |
| Recommendation | **Preferred** | Legacy/specific needs |

## Connection Pooling

### SQLx

```rust
let pool = PgPoolOptions::new()
    .max_connections(5)
    .acquire_timeout(Duration::from_secs(3))
    .connect(&database_url)
    .await?;
```

### Diesel with r2d2

```rust
use diesel::r2d2::{Pool, ConnectionManager};
use diesel::pg::PgConnection;

type DbPool = Pool<ConnectionManager<PgConnection>>;

fn establish_pool(database_url: &str) -> DbPool {
    let manager = ConnectionManager::<PgConnection>::new(database_url);
    Pool::builder()
        .max_size(5)
        .build(manager)
        .expect("Failed to create pool")
}
```

## Testing with Databases

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use sqlx::PgPool;
    
    async fn setup_test_db() -> PgPool {
        let pool = PgPool::connect("postgres://test@localhost/test_db").await.unwrap();
        sqlx::migrate!().run(&pool).await.unwrap();
        pool
    }
    
    #[sqlx::test]
    async fn test_create_user(pool: PgPool) {
        let user = create_user(&pool, "Test", "test@example.com").await.unwrap();
        assert_eq!(user.name, "Test");
    }
}
```
