# Apple Design System

## 1. Visual Theme
- **Atmosphere**: Premium, airy, photography-driven, effortless luxury.
- **Philosophy**: Less but better. Focus on clarity and high-quality materials.

## 2. Color Palette
- `background`: `#FFFFFF` (Light) / `#000000` (Hero Dark)
- `foreground`: `#1d1d1f` (Near Black)
- `interactive`:
  - `blue`: `#0071e3` (Primary CTA)
  - `link`: `#0066cc`

## 3. Typography
- **Primary Font**: `SF Pro Display`
- **Secondary Font**: `SF Pro Text`
- **Hierarchy**:
  - `Display Hero`: 56px / 600 / 1.07 / -0.28px
  - `Section Heading`: 40px / 600 / 1.10
  - `Body`: 17px / 400 / 1.47

## 4. Components
- **Buttons**:
  - `Primary`: Apple Blue background, Pill shape (980px/999px radius).
  - `Outline`: 1px border, blue text.
- **Navigation**:
  - `Glass`: Translucent with heavy blur (backdrop-filter: blur(20px)).

## 5. Spacing Scale
- 2, 4, 8, 10, 14, 17, 20, 24

## 6. Border Radius
- 8px (Buttons/Cards), 12px (Features), 980px (Pills)
