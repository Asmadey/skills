# Vercel Design System

## 1. Visual Theme
- **Atmosphere**: Developer-focused, minimalist, high-precision, monochrome.
- **Philosophy**: Content-first, typography-driven, zero-clutter.

## 2. Color Palette
- `background`: `#FFFFFF`
- `foreground`: `#171717` (Vercel Black)
- `accents`:
  - `blue`: `#0070f3` (Console/Interactive)
  - `pink`: `#eb367f` (Syntax/Active)
  - `purple`: `#7928ca` (Syntax)

## 3. Typography
- **Primary Font**: `Geist`
- **Secondary Font**: `Geist Mono`
- **Hierarchy**:
  - `Display Hero`: 48px / 600 / 1.0 / -2.4px
  - `Section Heading`: 40px / 600 / 1.2 / -2.4px
  - `Body`: 16px / 400 / 1.5

## 4. Components
- **Buttons**:
  - `Primary`: Black background, white text, 6px radius.
  - `Ghost`: No background, border on hover.
- **Cards**:
  - `Radius`: 8px
  - `Shadow`: Subtle ring (Level 1) or elevated with lift (Level 2).

## 5. Spacing Scale
- 2, 4, 6, 8, 12, 16, 32, 40

## 6. Border Radius
- 2px (Code), 6px (Buttons), 8px (Cards), 9999px (Badges)
