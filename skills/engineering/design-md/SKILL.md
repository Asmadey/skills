# Awesome Design MD

## 1. Когда использовать
- **Старт проекта**: Чтобы задать единый визуальный язык для всех последующих генераций.
- **Смена стиля**: Чтобы мгновенно перекрасить весь интерфейс через один Markdown-файл.
- **Синхронизация Агентов**: Чтобы любой ИИ-агент (Antigravity, Cursor, Stitch) знал точно, какие HEX-коды и шрифты использовать.

## 2. Позиционирование (Design Stack)
- **`design-md`** (Этот скилл): **Правила (Logic)**. Твой "Конституционный документ". Хранится в `DESIGN.md`.
- **`taste-skill`**: **Мастерство (Implementation)**. Используй его для написания сложного кода, следующего правилам из `DESIGN.md`.
- **`ui-ux-pro-max`**: **Референсы (Database)**. Огромная база стилей для вдохновения, если `DESIGN.md` еще не создан.

## 3. Workflow (Алгоритм работы)
1.  **Выбор стиля**: Выбери один из шаблонов в `resources/templates/` (например, `vercel.md` или `apple.md`).
2.  **Установка**: Скопируй содержимое шаблона в файл `DESIGN.md` в корне текущего проекта.
3.  **Активация**: Скажи мне: *"Используй DESIGN.md для создания [компонента/страницы]"*.
4.  **Валидация**: Я буду проверять каждый сгенерированный элемент на соответствие токенам из этого файла.

## 4. Ресурсы
- `resources/templates/`: Локальные шаблоны (Vercel, Apple, Stripe и др.)
- `examples/`: Огромный список внешних ресурсов и ссылок на другие системы.

> [!TIP]
> Markdown — лучший формат для ИИ. Не нужно парсить JSON или заглядывать в Figma, чтобы узнать цвет кнопки. Просто положи `DESIGN.md` в корень!
