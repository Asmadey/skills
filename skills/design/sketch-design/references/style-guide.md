# Style Guide · Sketch Design

Руководство по дизайну, цветовым палитрам, типографике и композиции рисованных скетч-презентаций и диаграмм в стиле Excalidraw / Whiteboard.

---

## 🎨 Цветовая модель и токены

### Базовые поверхности
- `paper` (`#faf8f5`): тёплый белый лист бумаги слайда.
- `desk` (`#ece7df`): окружающий фон «стола» вокруг активного холста с точечной сеткой `line`.
- `line` (`rgba(30, 30, 30, 0.08)`): тонкие точки координатной сетки (шаг 24px).
- `ink` (`#1e1e1e`): насыщенный графитовый цвет всех рукописных контуров и основного текста.
- `muted` (`#5e5e5e`): приглушённый цвет для пометок маркером (`sk-note`) и вторичных подписей.

### Палитра тонов (Tone System)
**Правило 1 тона на слайд:** у каждого слайда есть ведущий тон (`tone="orange|green|purple|pink|blue|teal|yellow|red"`).
Им окрашиваются:
1. Номер слайда в кружке (`*-tint` фон, `ink` цифра и контур).
2. Подчёркивание заголовка (`strong` цвет).
3. Акцентные стрелки и ключевые рамки (`line="tone"`).

| Тон | Strong (акцент, линии) | Tint (пастельная заливка) | Семантическое назначение |
| :--- | :--- | :--- | :--- |
| `orange` | `#bf4520` (терракотовый) | `rgba(191, 69, 32, 0.12)` | Обложки, вводные тезисы, энергия |
| `green` | `#2b7a4b` (зелёный маркер) | `rgba(43, 122, 75, 0.12)` | Рекомендуемый вариант, успех, «как надо» |
| `purple` | `#6941c6` (фиолетовый) | `rgba(105, 65, 198, 0.12)` | Реплики ИИ/Claude, алгоритмы, магия |
| `blue` | `#175cd3` (синий) | `rgba(23, 92, 211, 0.12)` | Реплики человека, чат, пользователь |
| `teal` | `#0e7090` (бирюзовый) | `rgba(14, 112, 144, 0.12)` | Данные, аналитика, структура |
| `pink` | `#c01048` (малиновый) | `rgba(192, 16, 72, 0.12)` | Нестандартный подход, креатив |
| `yellow` | `#b54708` (охра / хайлайтер) | `rgba(247, 144, 9, 0.18)` | Маркер-выделитель, ключевое слово |
| `red` | `#b42318` (красный маркер) | `rgba(180, 35, 24, 0.12)` | Ошибка, антипаттерн, «было плохо» |
| `gray` | `#475467` (нейтральный серый)| `rgba(71, 84, 103, 0.08)` | Команды, файлы, нейтральные блоки |

> **Правило контраста:** Больше трёх тонов заливки на одном слайде — визуальный шум. Допустимо 1–2 тона плюс `gray-tint`.

## ✍️ Типографика

Все тексты набираются рукописным шрифтом с поддержкой кириллицы, а технические сущности — моноширинным шрифтом.

- **Основной рукописный (`hand`):** `Pangolin` (Google Fonts, нативная кириллица `U+0400-045F`).
- **Технический моно (`mono`):** `JetBrains Mono` (команды, пути, имена файлов, токены).

### Шкала размеров на холсте 1600 × 900 px
| Класс / Элемент | Размер | Назначение |
| :--- | :---: | :--- |
| `sk-cover` | 120px | Заголовок главной обложки доклада |
| `sk-display` / `sk-title` | 64–72px | Заголовок слайда (короткий императив) |
| `sk-heading` | 46px | Заголовки колонок и этапов («1. Вход», «2. Сборка») |
| `sk-body` | 36px | Текст по умолчанию внутри карточек |
| `sk-note` | 32–34px | Рукописные реплики и пометки на полях |
| `sk-caption` | 28px | Вывод/мораль слайда внизу по центру |
| `sk-small` | 26px | Подписи к документам, легенда |
| `sk-code` | 30px | Команды CLI, имена файлов в `sk-chip` |
| `sk-code-sm` | 22px | Минимальный допустимый технический размер |

> **Порог читаемости:** Меньше 22px на сцене 1600×900 использовать запрещено (на экране ноутбука это ~15px).

## 📐 Сетка и композиция

1. **Разрешение сцены:** строго фиксированное `1600 × 900 px`.
2. **Автоматический скейл:** сцена подгоняется под размер окна браузера без полос прокрутки через `transform: scale(min(W/1600, H/900))`.
3. **Безопасная рабочая зона:**
   - По вертикали: от `y = 200px` до `y = 800px`.
   - По горизонтали: поля слева и справа по `80px`.
   - Заголовок `sk-title`: автоматически центрируется на `top: 54px`.
   - Мораль `sk-caption`: по центру на `bottom: 40px`.
4. **Воздух и плотность:**
   - Оптимально: **3–7 предметов на слайде**.
   - Не стремиться заполнить всё пространство сразу — пустота справа на шаге 1 нормальна, её займет шаг 2.
5. **Направление мысли:** слева направо (Причина слева → стрелка `sk-arrow` → Результат справа).
6. **Лёгкий джиттер от руки:** используйте атрибут `rot="-1.5"` или `rot="1"` для естественного живого наклона карточек.
