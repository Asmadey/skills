ROLE DESIGN THE FDE PARADOX

Three people in one. Why this profile wins.

All production AI deployments require three distinct disciplines, but almost nobody holds all three in one person.
01 · THE OPERATOR
Understands the actual work. Finance, legal, sales, ops. Distinguishes theater from actual decision-making.
02 · THE SOFTWARE ENGINEER
Ships production code into systems of record. Salesforce, SAP, NetSuite, Workday. Auth, rollback, APIs and security.
03 · THE AI ENGINEER
Builds evals & model-agnostic harness. Knows prompt vulnerabilities, token limits and deterministic verifiers.
The intersection is the Forward Deployed Engineer (FDE).
Consultancies have #1. Dev shops have #2. AI labs have #3. Leaders fuse them.

TACTICAL SUMMARY THE SIX RULES

So don't apply AI. Ground it.

Six principles that turn fragile prompt chains into high-margin enterprise infrastructure.
RULE 01

Find the Real Process

Interviews uncover the 'why'. Auditing the raw logs and inboxes uncovers the 'what'.

RULE 02

Sort Before Prompting

Delete unnecessary steps first, automate with plain deterministic code second, use LLMs third.

RULE 03

Baseline the Metrics

Write touch time and error rates on the wall before shipping any agent. Proof requires baselines.
