# Notte Web Agent

Notte — это посредник между ИИ и вебом, преобразующий сложные HTML-страницы в структурированные карты данных, понятные для LLM.

## 1. Когда использовать
- Парсинг сайтов без API или с сильной защитой (LinkedIn, корпоративные порталы).
- Автоматическое заполнение форм и навигация.
- Сбор данных с визуальным контролем процесса через Notte Studio.
- Запуск сотен параллельных браузерных сессий (Serverless).

## 2. Валидация и возможности
- [ ] Проверить баланс/доступ в [Notte Console](https://console.notte.cc/).
- [ ] Убедиться, что `NOTTE_API_KEY` настроен в `mcp_config.json`.
- [ ] Возможности: Stealth mode, решение капч, резидентские прокси, структурированный скрапинг.

## 3. Команды (через MCP)

### Управление сессиями
- `notte_start_session`: Запуск облачного браузера.
- `notte_list_sessions`: Просмотр активных сессий.
- `notte_stop_session`: Завершение сессии.

### Взаимодействие и Скрапинг
- `notte_operator`: Основной инструмент для выполнения задачи на сайте (укажите URL и цель).
- `notte_observe`: Анализ элементов и доступных действий на странице.
- `notte_scrape`: Извлечение структурированных данных.
- `notte_step`: Выполнение конкретного шага (клик, ввод текста).
- `notte_screenshot`: Снимок страницы.

## 4. Сценарии использования
### Анализ истории Telegram
Используйте `web.telegram.org` вместе с `notte_operator` для выгрузки истории чатов, последующего анализа через LLM и отправки отчетов в n8n/Notion.

### Сбор резюме
Навигация по сайтам поиска работы, фильтрация по критериям и сохранение результатов в структурированном виде.
