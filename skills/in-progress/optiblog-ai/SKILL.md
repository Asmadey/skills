# OptiBlogAi

## 1. Когда использовать
- Для автоматического исследования ключевых слов и анализа конкурентов в поисковой выдаче.
- Для генерации качественных, SEO-оптимизированных постов в блог.
- Для проверки качества контента через цикл обратной связи (breakeven assessment).

## 2. Валидация и требования
- [ ] Python 3.10+ установлен: `python --version`
- [ ] Ключи API (Groq/Gemini) прописаны в `.env`
- [ ] Установлены браузеры Playwright: `playwright install`
- [ ] Виртуальное окружение активировано.

## 3. Процесс работы (Workflow)
- [ ] Шаг 1: Настройка параметров в `.env`.
- [ ] Шаг 2: Запуск основного скрипта: `python src/main.py`.
- [ ] Шаг 3: Проверка результатов в папке вывода (output).

## 4. Инструкции (Степени свободы)
### Heuristics (Высокая свобода)
- Используйте Groq для быстрой генерации, Gemini для глубокого анализа.
- Экспериментируйте с промптами в `src/prompts/` (если применимо).

### Templates (Низкая свобода)
```bash
# Стандартный запуск
python src/main.py
```

## 5. Ресурсы
- `scripts/`: Скрипты развертывания и настройки.
- `docs/`: Подробная архитектура и этические нормы.
- `optiblogai-site/`: Исходный код веб-интерфейса (Next.js).
