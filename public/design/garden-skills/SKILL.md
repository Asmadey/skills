# 🌿 Garden Skills Suite

Комплексный пакет инженерных навыков веб-дизайна, презентаций и оформления контента от ConardLi. Пакет объединяет визуальный инжиниринг, динамические веб-презентации, типографику статей и генеративное медиа.

---

| Под-навык | Путь к манифесту | Назначение и ключевые возможности |

| **`web-design-engineer`** | [`skills/web-design-engineer/SKILL.md`](skills/web-design-engineer/SKILL.md) | **Визуальный фронтенд-инжиниринг**. Создание и редизайн браузерных артефактов (HTML/CSS/JS/React): лендинги, дашборды, интерактивные прототипы, анимации, дизайн-системы и UI/UX QA. |
| **`web-video-presentation`** | [`skills/web-video-presentation/SKILL.md`](skills/web-video-presentation/SKILL.md) | **Интерактивные 16:9 веб-презентации**. ## 🚀 Режимы использования

### 1. Разработка веб-интерфейса и прототипов
При необходимости создать стильный лендинг, дашборд или интерактивный компонент обратитесь к под-навыку:
```
skills/public/design/garden-skills/skills/web-design-engineer/SKILL.md
```

### 2. Создание интерактивной веб-презентации (Video-Like Presentation)
Для генерации динамической презентации 16:9 с пошаговым темпом и акцентом на контент:
```
skills/public/design/garden-skills/skills/web-video-presentation/SKILL.md
```

### 3. Оформление материалов в автономную веб-статью
Для верстки руководства, отчета или документации в формате автономного HTML-файла:
```
skills/public/design/garden-skills/skills/beautiful-article/SKILL.md
```

### 4. Генерация графических ассетов и иллюстраций
Для подбора идеального промпта и генерации баннеров, иконок или иллюстраций:
```
skills/public/design/garden-skills/skills/gpt-image-2/SKILL.md
```
