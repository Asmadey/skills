# AJTBD: Построение Графа Работ

## 1. Когда использовать
- При проектировании новых фич или продуктов.
- Для поиска точек роста ценности (Value Creation).
- Для анализа конкурентов (какую часть работы они забирают на себя).
- Чтобы найти "Налоговые работы" (лишние действия), которые можно убить или автоматизировать.

## 2. Ключевые понятия
- **Job (Работа):** Прогресс, которого человек хочет достичь в конкретных обстоятельствах.
- **Job Graph (Граф Работ):** Иерархическая структура работ. Чтобы выполнить большую работу (Parent Job), нужно выполнить набор маленьких (Sub-jobs).
- **Tax Job (Налоговая работа):** Действие, которое не несет прямой ценности, но вынуждено (настройка, ожидание, исправление ошибок).
- **Value (Ценность):** Отношение полученной пользы к затраченным усилиям (время, деньги, стресс).

## 3. Механики создания ценности (Value Mechanics)
1.  **Kill (Убить):** Устранить необходимость выполнения работы. (Самая сильная механика).
2.  **Combine (Объединить):** Выполнить несколько работ одним действием.
3.  **Delegate/Automate (Делегировать):** Переложить выполнение на алгоритм/ИИ.
4.  **Fix (Починить):** Устранить барьеры и ошибки.

## 4. Workflow (Алгоритм)

- [ ] **Шаг 1: Определить фокусную работу.** Какую задачу хочет решить пользователь "прямо сейчас"?
- [ ] **Шаг 2: Построить иерархию (3 уровня).**
    -   *Higher Level:* Зачем ему это нужно? (Meta-Job)
    -   *Current Level:* Что конкретно он делает? (Core Job)
    -   *Lower Level:* Из каких шагов состоит процесс? (Micro-Jobs)
- [ ] **Шаг 3: Найти проблемы (Red Nodes).** Выделить шаги, где пользователь теряет энергию (ошибки, рутина, ожидание). Это "Налоговые работы".
- [ ] **Шаг 4: Применить механики.** Как мы можем эти красные узлы превратить в зеленые? (Kill, Automate, etc.)
- [ ] **Шаг 5: Визуализировать через Mermaid.** Создать наглядную диаграмму.

## 5. Формат визуализации (Mermaid)

Используйте диаграмму `graph TD` или `mindmap`.
Цветовое кодирование:
- **Зеленый:** Ценность / Результат.
- **Желтый:** Процесс / Работа.
- **Красный:** Проблема / Налоговая работа.
- **Синий:** Решение / Продукт.

Пример кода Mermaid см. в `resources/template.md`.
