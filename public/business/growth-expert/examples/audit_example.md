# Пример аудита: Growth Audit - App "SaaS Tool X"

## 1. ПЕРВОЕ ВПЕЧАТЛЕНИЕ (тест за 5 секунд)
- **УТП**: "Автоматизируйте маркетинг за 10 минут".
- **Аудитория**: Соло-пренеры и малый бизнес.
- **CTA**: "Начать бесплатно" (очень заметно).
- **Оценка**: 9/10

## 2. СИГНАЛЫ РОСТА
- **SEO**: Блог обновлялся неделю назад. Много полезных гайдов.
- **Social Proof**: 3 логотипа известных компаний (Forbes, WSJ упоминания).
- **Trust Signals**: GDPR Ready, SSL.
- **CTA**: Один основной фокус.
- **Lead Gen**: Есть форма подписки на рассылку "Growth Tips".

## 3. Вероятная воронка
[Twitter Ads] → [Landing Page] → [Free Trial] → [Paid Subscription]
*Слабое звено*: Переход из Free Trial в Paid (нужно больше инфы о выгоде платных фич).

## 4. ТРИ ГЛАВНЫХ МЕТОДА РОСТА
1. Добавить видео-демо на главный экран — потому что продукт сложный визуально.
2. Использовать чек-лист успеха в онбординге — для повышения активации.
3. Добавить отзывы с лицами реальных людей — сейчас только логотипы, нет личного доверия.

## 5. То, чего я не могу разглядеть со стороны
- CAC (Cost Per Acquisition).
- Churn rate из режима триала.
- Средний чек LTV.

## 6. КОНКУРЕНТОСПОСОБНЫЙ АНАЛИТИК (бонус)
Страница: **ВПЕРЕД** типичного конкурента.
Отраслевой стандарт превышен по качеству контента и простоте CTA.
